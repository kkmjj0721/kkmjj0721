## 🤖 About Me

我是一名专注于**机器人控制与智能决策**的研究者 / 工程师。热衷于将深度强化学习（DRL）算法应用到真实硬件与复杂物理仿真环境中。

* 🧠 **核心研究:** 具身智能 (Embodied AI) / 机器人运动控制 (Locomotion & Manipulation)
* 🛠️ **仿真环境:** 熟练使用 MuJoCo, Gazebo 进行全物理精度仿真与算法验证
* 💬 **交流探讨:** 欢迎聊聊 DDPG/PPO 调参、ROS 2 通信机制以及 C++ 内存优化
